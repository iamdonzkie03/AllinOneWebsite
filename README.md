# Commonplace Portal (PHP/MySQL starter)

A starter application architecture for a multi-category publishing and marketplace portal:
Creative Arts, E-Commerce, Property Listings, Blog, Entertainment, and News.

## Stack
- PHP 8.3+ (modern PHP; use a currently supported PHP release)
- MySQL 8+
- HTML5, CSS3, JavaScript, jQuery 3.x
- PDO prepared statements, password hashing, session-based authentication

## Roles and workflow
- Viewer: browses only approved/published content and can register.
- Pending account: registration waits for administrator credential review.
- Creator: once approved, enters personal workspace and manages own drafts (create/edit/delete/search); submission is not public until approved/published.
- System Administrator: reviews accounts, approves/rejects access, moderates content, and manages categories.

## Setup
1. Put the `allinoneweb` directory under your PHP server's web root.
2. Create a MySQL database and import `database/schema.sql`.
3. Copy `config/config.example.php` to `config/config.php` and set database credentials.
4. Open the site at `http://localhost/allinoneweb/`. The homepage `index.php` is in the project root; account and admin pages remain in `public/`.
5. Create the first administrator using a secure one-time setup process or insert a password hash generated by `password_hash()` into the users table. Do not leave a public default administrator password.
6. Enable HTTPS in production and set secure cookie/session options.

This is a starter scaffold, not a production-ready deployment. Add CSRF protection, rate limiting, email verification, audit logging, file-upload scanning, backups, and deployment-specific hardening before public launch.
